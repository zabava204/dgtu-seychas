# Правила для ИИ-агентов в этом репозитории

Этот файл читают ИИ-ассистенты (Claude Code, Codex и другие) перед любой задачей. Человек ставит задачу, агент пишет код, второй агент проверяет.

## Что это

«ДГТУ.Сейчас» — концепт личного кабинета студента для конкурса MGIMO AI Challenge («Цифровой деканат будущего»). Не официальный сервис ДГТУ. Все данные синтетические.

Главный сценарий: магистрант Илья заказывает справку для налогового вычета за прошлый год → деканат берёт в работу и формирует PDF → Илья получает PDF и уведомление.

## Стек и структура

- Node.js 22, Express 5, SQLite (better-sqlite3), серверный рендеринг шаблонной функцией `html`` ` с экранированием (`src/views/html.js`).
- `src/server.js` — маршруты и проверки прав; `src/model.js` — запросы к БД; `src/seed.js` — демо-данные; `src/views/*` — страницы.
- `src/grades.js`, `src/tax.js` — расчёты баллов и вычета. `src/assistant.js` — помощник (GigaChat + правила).
- `test/app.test.js` — автотесты (`npm test`). Запуск: `npm start`, порт 3000.

## Неизменяемые правила

1. **Только синтетические данные.** Никаких настоящих ФИО, оценок, номеров зачёток, приказов. Демо-ИНН начинается с кода региона 00 — не может принадлежать человеку.
2. **Права проверяет сервер.** Чужая заявка, файл, PDF → 404 (не 403, чтобы не раскрывать существование). Действия деканата — только роль `staff`. Любой новый маршрут со студенческими данными — через `student`/`staff` и `M.canSee`.
3. **Ключи только в переменных окружения** (`GIGACHAT_AUTH_KEY`, `SESSION_SECRET`). Никогда в коде, в браузере, в логах.
4. **Числа считает программа, не языковая модель.** Баллы, суммы вычета, даты, статусы — детерминированные ответы (`exact`, источник `calc`). GigaChat отвечает только на свободные вопросы. Причина: модель насчитала «212 баллов» вместо 47 (см. `docs/reviews.md`).
5. **Справка для вычета — только за закончившийся год.** Проверка в форме, на сервере и в тесте.
6. **Формулировки — как в кабинете ДГТУ**: «Справка об обучении», «заказчик по договору», статусы справок «Заказана → В обработке → Готова». К студенту — на «ты». Язык интерфейса и комментариев — русский. Исключение: на вопрос по-английски помощник отвечает по-английски (`src/assistant-en.js`, факты — тоже расчётом); официальные справки — только на русском.
7. **Честные обещания.** Не писать того, чего прототип не делает (push на закрытый телефон, «анонимно», «мы уже проверили»). Демо-правила помечать как демо-правила.
8. **Мобильная версия от 360 px.** После изменения экрана — проверить на 360 и 390 px, что нет горизонтальной прокрутки. Проверять и в версии для слабовидящих (cookie `lv=1`, класс `lv` на `<html>`): крупнее текст, выше контраст, у всех значков есть подпись для экранного диктора.

## Как работать

1. Прочитать задачу и этот файл. Если задача спорная — задать один вопрос человеку.
2. Внести изменение маленьким шагом, добавить или обновить автотест.
3. `npm test` — все тесты зелёные. Снять скриншоты изменённых экранов (Playwright) и посмотреть их.
4. Коммит с понятным русским сообщением. Пуш в `main` разворачивается на Timeweb автоматически (~3 минуты).
5. Проверить живой сайт. Записать найденную ошибку ИИ в журнал (PDF-описание, раздел «Цепочка ошибок»).

## Независимая проверка

Перед крупным шагом пакет передаётся второму агенту (ChatGPT / Codex) по шаблону `docs/review-prompt.md`. Его замечания агент-разработчик оценивает по одному: принять, отклонить с причиной, уточнить у человека. Итоги — в `docs/reviews.md`.
