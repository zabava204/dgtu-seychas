# ДГТУ.Сейчас — цифровой деканат в телефоне

Концепт личного кабинета студента для MGIMO AI Challenge, номинация «Вайб-кодинг», задание «Цифровой деканат будущего».
**Не официальный сервис ДГТУ. Все данные о людях, оценках и заявках синтетические.**

Главная идея: кабинет отвечает на вопрос студента «что мне нужно сделать сейчас», а не показывает меню разделов.
Четыре раздела: **Сегодня · Учёба · Заявки · Профиль**. Поиск в шапке находит разделы; помощник отвечает на вопросы по данным кабинета.

## Что внутри

- **Сегодня:** приветствие; карточка «Сейчас» — текущая или ближайшая пара с корпусом, этажом и «Как пройти»; помощник; «Следующий шаг» — одно действие (готовый черновик, затем риск допуска); остальные пункты раскрываются в «Других задачах»; быстрые действия по ситуации.
- **Учёба:** расписание на день и на неделю (верхняя / нижняя неделя), зачёты и экзамены прямо в расписании, в пустой день — ближайшая пара. Оценки по балльно-рейтинговой системе. Сессия: даты зачётов, экзаменов и консультаций, допуск по каждой дисциплине. Если порога не хватает, «Разобраться» открывает расчёт кабинета (сейчас, порог, недобор, что уже есть в журнале) и черновик сообщения преподавателю: цифры подставляет программа, письмо не отправляется. «План на 7 дней» ставит эти задачи в свободные окна между парами (30–120 минут, день или вечер); отметка «сделано» баллы не меняет, ближайшая задача видна на «Сегодня». Зачётная книжка со средним баллом. НИР для магистрантов.
- **Заявки:** «Жизненные ситуации» — пакет справок по данным студента одной кнопкой; справка об обучении (Форма 2), о размере стипендии, для налогового вычета (КНД 1151158), заявление на материальную помощь. Группы «Нужно твоё действие», «Черновики», «На рассмотрении», «Завершённые»; этапы с именем сотрудника и сроком, переписка, загрузка документа, PDF.
- **Уведомления:** изменения расписания, заявки, сроки сдачи, объявления; фильтр по категориям; каждое ведёт на конкретную пару, дисциплину или заявку.
- **Профиль:** профиль, «Мои документы» — студенческий билет и зачётная книжка; «Мой деканат», настройки уведомлений, «Помощь и поддержка» (не передаёт данные деканату), сброс демо.
- **Деканат:** очередь со счётчиками, карточка заявки (данные студента, оплаты по договору или выплаты стипендии), «Взять в работу» → затем «Запросить документ», «Отклонить», «Сформировать PDF», переписка, объявление.
- **Помощник:** расписание на любой день, баллы и допуск, даты сессии, статус заявок, средний балл, НИР, стипендию и сумму вычета считает программа по данным кабинета (пометка «Расчёт по данным кабинета»). GigaChat отвечает только на свободные вопросы и не называет цифр и сроков. Кнопки-действия формирует сервер. На вопрос по-английски помощник отвечает по-английски — для иностранных студентов (первая часть английской версии).
- **Версия для слабовидящих:** значок «глаз» в шапке, ссылка на входе и в «Профиле». Крупнее текст, высокий контраст, видимые границы и подчёркнутые ссылки, без анимаций; выбор запоминается в браузере. Все значки подписаны для экранного диктора.

## Безопасность и данные

- Пароли хранятся в виде хэша bcrypt; сессия — подписанная cookie (`httpOnly`, `SameSite=Lax`, `Secure` в продакшене).
- Права проверяются на сервере: студент видит только свои заявки, файлы и PDF (чужие — 404); действия деканата доступны только роли `staff`.
- POST-запросы с чужих сайтов отклоняются; заголовки CSP, `X-Frame-Options`, `nosniff`.
- Загрузка файлов: только PDF/JPG/PNG до 5 МБ, имя на диске — случайное.
- Ключ GigaChat хранится только в переменных окружения сервера, в браузер не попадает. В свободном вопросе модели передаются текст вопроса, до шести сообщений истории и выбранные справочные сведения. Автоматическая подборка фактов исключает баллы, суммы и статусы заявок. Текст, который студент сам вводит в чат, может попасть в модель.
- Журнал помощника хранит только тип вопроса и источник ответа, без текста вопроса.
- Уведомления браузера показывают только «Есть изменение в заявке» — без содержания.

## Запуск

```bash
npm install
npm test        # проверки прав доступа и сквозного сценария
npm start       # http://localhost:3000
```

Переменные окружения — в `.env.example`. Для продакшена обязательно `SESSION_SECRET`; для помощника — `GIGACHAT_AUTH_KEY`.

**Хостинг:** Timeweb Cloud App Platform, регион Москва, деплой по `Dockerfile` (Node.js 22, порт 3000) или как Node.js-приложение с командой запуска `npm start`.
Сертификаты НУЦ Минцифры для GigaChat ставятся при сборке образа, а без Docker скачиваются при первом запросе с адреса из документации Сбера и кэшируются в папке данных.

Демо-данные создаются при первом запуске (SQLite в папке `data/`). Даты заявок, пар и дедлайнов считаются от текущего дня, поэтому демо выглядит актуально в любой день.

## Масштабирование

Прототип работает на одном сервере с SQLite — это проверено для демонстрационных сценариев. Нагрузочное тестирование на тысячах студентов не проводилось. Для вуза целиком код рассчитан на замену без переделки экранов:

- **БД:** для перехода на PostgreSQL потребуется изменить слой данных, схему SQLite и прямые SQL-запросы в маршрутах; интерфейс можно сохранить.
- **Сервер без состояния:** сессия хранится в подписанной cookie, но для нескольких экземпляров нужны общая БД и файловое хранилище; локальные лимиты входа также потребуется вынести в общее хранилище.
- **Файлы:** загрузки лежат в одной папке со случайными именами — переносятся в S3-совместимое хранилище.
- **Помощник:** запросы к GigaChat идут через очередь по одному; расчёты (баллы, вычет, даты) не нагружают модель.
- **Интеграции:** расписание, оценки и заявки берутся из своих таблиц — в рабочей версии их заполняют выгрузки из учётных систем вуза.

## Ограничения прототипа

- Нет интеграции с реальными системами ДГТУ; «Как пройти» — демо-маршрут.
- Push-уведомления на закрытый телефон не отправляются: уведомления видны в кабинете и в браузере, пока кабинет открыт.
- PDF-справка — демонстрационный образец с водяным знаком, без подписи и печати.
- Сроки и правила заявок, допуск к сессии по порогу баллов, суммы стипендии — демо-правила и синтетические данные концепта, не нормативы вуза.
- Телефоны в разделе «Помощь и поддержка» нужно сверить с официальными источниками перед реальным запуском.
