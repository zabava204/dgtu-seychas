# ДГТУ.Сейчас — цифровой деканат в телефоне

Концепт личного кабинета студента для MGIMO AI Challenge, номинация «Вайб-кодинг», задание «Цифровой деканат будущего».
**Не официальный сервис ДГТУ. Все люди, оценки и заявки вымышленные.**

Главная идея: кабинет отвечает на вопрос студента «что мне нужно сделать сейчас», а не показывает меню разделов.
Четыре раздела: **Сегодня · Учёба · Заявки · Я**. Поиск «Что нужно?» открывает помощника.

## Сквозной сценарий (2 минуты): справка для налогового вычета

Илья — магистрант 2 курса на контракте, работает. Чтобы вернуть 13% от оплаты обучения за прошлый год, ему нужна справка из вуза об оплате образовательных услуг. Справку выдают за закончившийся календарный год: за текущий год её можно заказать только с января.

1. Войти как **Илья** → «Сегодня» → «Справка для налогового вычета» → **Проверить**. Кабинет сам проверил условия по договору: обучение платное, платил сам Илья, оплата с 2024 года — значит, хватит одной справки. Видно, сколько оплачено за прошлый год и сколько можно вернуть; текущий год показан, но выбрать его нельзя — «можно заказать с января». → **Отправить заявку**.
2. В другом окне войти как **dekanat** → заявка в «Новых» → в карточке видны оплаты по договору → **Взять в работу** → **Сформировать PDF-справку**.
3. Вернуться к Илье → «Заявки» → справка готова → **Открыть PDF**. Рядом — «Как получить вычет»: справку прикладывают к декларации 3-НДФЛ в личном кабинете налогоплательщика.
4. Дополнительно: Анна (бюджет) пробует заказать такую же справку — кабинет объясняет, что оплат по договору нет. Анна загружает документ по заявке на матпомощь — заявка возвращается деканату.

Данные общие для всех проверяющих. Если сценарий уже кто-то прошёл, на странице входа есть кнопка **«Начать сценарий заново»**; кроме того, демо-данные сбрасываются каждую ночь в 3:00 МСК и кнопкой в кабинете деканата.

## Что внутри

- **Сегодня:** ближайшая пара с отсчётом и линией дня, изменения аудитории и времени, «Как пройти», список «Нужно сделать», сводка успеваемости.
- **Учёба:** расписание на день и на неделю (числитель/знаменатель), зачёты и экзамены прямо в расписании. Оценки со светофором и «что сделать, чтобы закрыть». **Сессия:** даты зачётов, экзаменов и консультаций, отсчёт дней и допуск по каждой дисциплине. **Зачётная книжка** за прошлые семестры со средним баллом. НИР для магистрантов.
- **Уведомления:** изменения расписания, заявки, сроки сдачи работ (за 2 дня и в день сдачи), объявления деканата; фильтр по категориям и настройки.
- **Справка для налогового вычета:** кабинет проверяет условия по оплатам договора, показывает сумму к возврату и объясняет, как получить вычет (подсказка по материалам ФНС, не налоговая консультация).
- **Заявки:** три группы — «Нужно твоё действие», «Ждут деканат», «Готовые». Маршрут заявки по этапам с именем сотрудника и сроком, загрузка документа, «Где взять справку», переписка, PDF.
- **Я:** профиль, «Мой деканат», настройки уведомлений по категориям, «Если тяжело» (не передаёт данные деканату).
- **Деканат:** очередь заявок со счётчиками, карточка заявки, действия, история, объявление студентам.
- **Помощник:** GigaChat отвечает по данным только текущего студента; кнопки-действия формирует сервер по правилам. Без ключа помощник отвечает по правилам.

## Безопасность и данные

- Пароли хранятся в виде хэша bcrypt; сессия — подписанная cookie (`httpOnly`, `SameSite=Lax`, `Secure` в продакшене).
- Права проверяются на сервере: студент видит только свои заявки, файлы и PDF (чужие — 404); действия деканата доступны только роли `staff`.
- POST-запросы с чужих сайтов отклоняются; заголовки CSP, `X-Frame-Options`, `nosniff`.
- Загрузка файлов: только PDF/JPG/PNG до 5 МБ, имя на диске — случайное.
- Ключ GigaChat хранится только в переменных окружения сервера, в браузер не попадает. В модель уходят имя, курс, группа, оценки и заявки текущего студента — без ФИО и номера зачётки.
- Журнал помощника хранит только тип вопроса и источник ответа, без текста вопроса.
- Уведомления браузера показывают только «Есть изменение в заявке» — без содержания.

## Запуск

```bash
npm install
npm test        # проверки прав доступа и сквозного сценария
npm start       # http://localhost:3000
```

Переменные окружения — в `.env.example`. Для продакшена обязательно `SESSION_SECRET`; для помощника — `GIGACHAT_AUTH_KEY`.

**Хостинг:** Timeweb Cloud App Platform, регион Москва, деплой по `Dockerfile` (Node.js 22, порт 3000) или как Node.js-приложение с командой запуска `npm start`.
Сертификаты НУЦ Минцифры для GigaChat ставятся при сборке образа, а без Docker скачиваются при первом запросе с адреса из документации Сбера и кэшируются в папке данных.

Демо-данные создаются при первом запуске (SQLite в папке `data/`). Даты заявок, пар и дедлайнов считаются от текущего дня, поэтому демо выглядит актуально в любой день.

## Масштабирование

Прототип работает на одном сервере с SQLite — этого хватает для демонстрации и факультета в несколько тысяч студентов (чтение страниц — миллисекунды, данные одного студента — десятки строк). Для вуза целиком код рассчитан на замену без переделки экранов:

- **БД:** все запросы собраны в `src/model.js` — SQLite меняется на PostgreSQL заменой этого слоя.
- **Сервер без состояния:** сессия хранится в подписанной cookie, поэтому экземпляров приложения можно запустить несколько за балансировщиком.
- **Файлы:** загрузки лежат в одной папке со случайными именами — переносятся в S3-совместимое хранилище.
- **Помощник:** запросы к GigaChat идут через очередь по одному; расчёты (баллы, вычет, даты) не нагружают модель.
- **Интеграции:** расписание, оценки и заявки берутся из своих таблиц — в рабочей версии их заполняют выгрузки из учётных систем вуза.

## Ограничения прототипа

- Нет интеграции с реальными системами ДГТУ; «Как пройти» — демо-маршрут.
- Push-уведомления на закрытый телефон не отправляются: уведомления видны в кабинете и в браузере, пока кабинет открыт.
- PDF-справка — демонстрационный образец с водяным знаком, без подписи и печати.
- Сроки и правила заявок, допуск к сессии по порогу баллов — демо-правила концепта, не нормативы вуза.
- Телефоны в разделе «Если тяжело» нужно сверить с официальными источниками перед реальным запуском.
