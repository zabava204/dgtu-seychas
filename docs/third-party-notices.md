Inter: SIL Open Font License 1.1. Полный текст: docs/licenses/Inter-OFL.txt. Официальный источник: https://github.com/rsms/inter/blob/master/LICENSE.txt.
Иконки и логотип проекта заданы SVG-разметкой; официальный логотип вуза не используется. Исторические макеты извлечены из прежнего PDF команды; актуальные скриншоты сняты с опубликованного прототипа.
Для отсутствующих в npm-архиве notices сохранены upstream-тексты с URL происхождения. Это технический перечень материалов, а не заключение юридической экспертизы.

У brotli и dfa npm-пакеты содержат декларацию MIT в README без отдельного полного текста. Декларации сохранены отдельно. У brotli также сохранены заголовки исходных файлов Google под Apache-2.0. Это ограничение комплектации оригинальных npm-пакетов отмечено явно.

В комплекте сохранены найденные в опубликованных npm-пакетах декларации и заголовки, а для Apache 2.0 приложен официальный текст: https://www.apache.org/licenses/LICENSE-2.0.txt.
