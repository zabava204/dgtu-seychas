ДГТУ.Сейчас. Цифровой деканат будущего

Прототип: https://zabava204-dgtu-seychas-e35f.twc1.net/

Тестовые аккаунты (пароль у всех demo2026):
anna: бакалавриат, бюджет, дневные учебные занятия
ilya: магистратура, обучение по договору, вечерние занятия и НИР
dekanat: сотрудник деканата
На странице входа есть вход одной кнопкой. В верхней части «Профиля» и кабинета сотрудника можно переключаться между аккаунтами без сброса данных.

Исходный код: https://github.com/zabava204/dgtu-seychas
Видео: ССЫЛКА НА ВИДЕО

Сценарии для проверки:
1. Илья заказывает справку для налогового вычета: «Сегодня» → «Продолжить заявку» → «Заказать справку» (если черновика нет: «Заявки» → «Новая заявка» → «Справка для налогового вычета»). Сотрудник деканата: «Новые» → заявка Ильи → «Взять в работу» → «Сформировать PDF-справку». Илья получает уведомление и открывает PDF в «Заявках».
2. Анна получает допуск к сессии: «Сегодня» → «Разобраться» → расчёт баллов и письмо преподавателю → «План на 7 дней».
3. Анна заказывает пакет справок: «Заявки» → «Новая заявка» → «Семья оформляет субсидию на ЖКУ» → две справки одной кнопкой. Сотрудник деканата видит их одной строкой «Пакет».
Доступность: значок «глаз» в шапке включает версию для слабовидящих, на вопрос по-английски помощник отвечает по-английски.

Все данные синтетические. Это конкурсный концепт, а не официальный сервис ДГТУ. Демо-данные общие для всех проверяющих. Чтобы пройти сценарий заново: «Профиль» → «Демонстрационный режим».
