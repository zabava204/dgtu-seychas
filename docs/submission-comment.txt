Прототип: https://zabava204-dgtu-seychas-e35f.twc1.net/

Тестовые аккаунты:
anna / demo2026 — бакалавриат, бюджет, дневные занятия.
ilya / demo2026 — магистратура, договор, вечерние занятия и НИР.
dekanat / demo2026 — сотрудник деканата.
На странице входа также есть кнопки демо-доступа. Вверху «Профиля» и кабинета сотрудника можно переключаться между тремя аккаунтами без сброса данных.

Код: https://github.com/zabava204/dgtu-seychas
Описание процесса — в прилагаемом PDF. В комплекте также есть архив исходников с обновлёнными материалами.

Основной сценарий: ilya → «Сегодня» → «Задачи и заявки» → «Продолжить заявку» у справки для вычета (запасной вход: «Заявки» → «Новая заявка» → «Справка для налогового вычета») → отчётный год и «Заказать справку»; dekanat → «Новые» → заявка Ильи → «Взять в работу» → «Сформировать PDF-справку»; ilya → «Заявки» → готовая справка → «Открыть PDF».
Второй сценарий: anna → «Сегодня» → первая задача «Допуск к сессии» → «Разобраться» → расчёт баллов и текст сообщения преподавателю → «План на 7 дней». Остальные задачи под «Ещё».
Третий сценарий: anna → «Заявки» → «Новая заявка» → «Семья оформляет субсидию на ЖКУ» → две справки одной кнопкой; dekanat → «Новые» → строка «Пакет · 2 справки».
Доступность: значок «глаз» в шапке включает версию для слабовидящих; на вопрос по-английски помощник отвечает по-английски.

Все данные синтетические. Это конкурсный концепт, не официальный сервис ДГТУ. Демо-данные общие для проверяющих; если сценарий уже пройден, его можно начать заново в «Профиле» → «Демонстрационный режим». Сброс затрагивает все демо-аккаунты.
