ДГТУ.Сейчас — «Цифровой деканат будущего»

Прототип: https://zabava204-dgtu-seychas-e35f.twc1.net/

Тестовые аккаунты:
anna / demo2026 — бакалавриат, бюджет, дневные пары.
ilya / demo2026 — магистратура, договор, вечерние пары и НИР.
dekanat / demo2026 — сотрудник деканата.
На странице входа также есть кнопки демо-доступа. Вверху «Профиля» и кабинета сотрудника можно переключаться между тремя аккаунтами без сброса данных.

Код: https://github.com/zabava204/dgtu-seychas
Описание процесса — в прилагаемом PDF. В комплекте также есть архив исходников с обновлёнными материалами.

Основной сценарий: ilya → «Сегодня» → «Задачи и заявки» → «Продолжить заявку» у справки для вычета (запасной вход: «Заявки» → «Новая заявка» → «Справка для налогового вычета») → выбрать доступный законченный год и заказать; dekanat → «Новые» → заявка Ильи → «Взять в работу» → «Сформировать PDF-справку»; ilya → «Заявки» → готовая справка → «Открыть PDF».
Второй сценарий: anna → «Сегодня» → первая задача «Допуск к сессии» → «Разобраться» → расчёт баллов и текст сообщения преподавателю → «План на 7 дней». Остальные задачи — под «Ещё».

Все данные вымышленные. Это конкурсный концепт, не официальный сервис ДГТУ. Демо-данные общие для проверяющих; если сценарий уже пройден, его можно начать заново в «Профиле» → «Демонстрационный режим». Сброс затрагивает все демо-аккаунты.
