# Независимые проверки и цепочка ошибок ИИ

Проверок было четыре (ChatGPT / Codex) плюс сверка с критериями. Ниже — что нашли и как исправили. Полная таблица с этапами — в PDF-описании.

| Задача | Ошибка ИИ | Кто нашёл | Исправление и проверка |
|---|---|---|---|
| Главный экран Анны | Справка для военкомата у девушки | Человек | Заменена на справку для проездного |
| Кабинет сотрудника | Заявки Анны записаны на других студентов | Второй агент | Единая временная линия; единый набор демо-данных в коде |
| Помощник | «Я уже проверил», «принимают без печати» — утверждения без основания | Второй агент | Ответ по данным кабинета + пометка «демо-правило» |
| Список заявок | Ссылка внутри ссылки — строка развалилась | Claude по своему скриншоту | Исправлена разметка, проверено на 360 px |
| Название раздела | «Жизнь» — калька; «Поддержка» звучит как техподдержка | Человек | Раздел отложен |
| Макеты v2 | Номера заявок расходились между экранами; старое меню из 5 разделов | Второй агент | Один маршрут заявки; меню из 4 разделов |
| Упрощение v2 | Пропали «Где взять справку» и «Забыли пароль?»; контраст 2,9:1 | Второй агент | Возвращены; контраст ~5,5:1; цели нажатия 44 px |
| Обзор практик | Цифры из пересказа вместо первоисточника | Второй агент | Исправлено по работе 2023 г. |
| Справки об обучении | Цели «для проездного» и справка для визы не нужны нашим студентам; «соцзащита» — разговорное название | Человек | Цели: льгота родителей по ЖКУ, работодателю, по месту требования; справка для визы убрана |
| Справка для вычета | Предлагалась справка за текущий 2026 год | Человек | Только закончившийся год: форма, сервер, тест |
| Поле ИНН | Шаблон проверки записан неверно — браузер не пропустил бы верный ИНН | Claude, самопроверка | Исправлено, проверка в тесте |
| Вход | Защита от подбора считала и успешные входы | Автотест | Считаются только неудачные попытки |
| Помощник (GigaChat) | Неверное определение «академической разницы» | Claude на живом сайте | Словарь вузовских терминов в системном промпте |
| Помощник (GigaChat) | Насчитал 212 баллов вместо 47 | Второй агент | Баллы, вычет, даты считает программа; тест-регрессия |
| Уведомление | Вело на расписание сегодня, а не на день изменения | Второй агент | Ссылка на день и пару с подсветкой; тест |
| «Сегодня» | Задача по НИР, которую нельзя выполнить в прототипе | Второй агент | Убрана |
| Сверка с критериями | Нет сессии и зачётки, неделя только по дням, нет напоминаний о сроках, «голые» страницы ошибок | Claude по критериям | Сессия с допуском, зачётная книжка, режим «Неделя», лента «Сроки», страницы ошибок; тесты |

| Дизайн | Серая шапка, мелкое меню и мелкий текст — выглядело слабее действующего кабинета ДГТУ | Человек | Фирменная шапка с приветствием, плитки быстрых действий, крупное меню с «капсулой», белые карточки |

**Вывод:** человек ловит то, чего нет в документах (практику вуза и жизненную логику); второй агент — расхождения и неподтверждённые утверждения; автотесты — то, что ломается только при запуске.
