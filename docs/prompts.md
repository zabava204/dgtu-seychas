## Как ставили задачи агенту

- **Сначала цель и ограничения, потом решение.** «Справку заказывают за полностью год» — правило из практики, агент сам переносит его в форму, сервер и тест.
- **Один вопрос вместо догадки.** Когда сценарий «справка родителям» не сошёлся с персонами (Анна на бюджете, Илья очно-заочно), агент спросил, человек выбрал «Илья, вычет за себя».
- **Проверка глазами.** После каждого экрана — скриншот на 360/390 px; после деплоя — проверка живого сайта во встроенном браузере.
- **Два агента.** Разработчик не проверяет сам себя: пакет уходит второму агенту по шаблону `docs/review-prompt.md`.
