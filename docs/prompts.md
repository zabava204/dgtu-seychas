## Как ставили задачи агенту

- **Сначала цель и ограничения, потом решение.** «Справку заказывают за полностью год» — правило из практики, агент сам переносит его в форму, сервер и тест.
- **Один вопрос вместо догадки.** Когда сценарий «справка родителям» не сошёлся с персонами (Анна на бюджете, Илья очно-заочно), агент спросил, человек выбрал «Илья, вычет за себя».
- **Проверка глазами.** После каждого экрана — скриншот на 360/390 px; после деплоя — проверка живого сайта во встроенном браузере.
- **Два агента.** Разработчик не проверяет сам себя: пакет уходит второму агенту по шаблону `docs/review-prompt.md`.

## Доработка 16 ноября: Codex Desktop

Ниже приведены запросы из текущего чата; прежняя таблица передаёт суть прошлых запросов и не является полной стенограммой.

- Пользователь: «Сделай личный кабинет, каждый раздел проанализовал, чтобы это был русский язык, принятый в приложениях… правильный UX, UI дизайн… правильное название, сокращения, поясняющий текст». Результат: широкая рабочая область, «Профиль», единые переходы, русские подписи, состояния сохранения и выбора справок.
- Задача независимому агенту: «Проведи самостоятельный аудит существующего UX и русских текстов всех разделов… Код не меняй». После реализации выполнено отдельное ревью диффа; исправлены три найденные регрессии.
- Проверки: формы без выбранных документов; сохранение при отключённом сервере и повтор после восстановления; 360/390 px, крупный шрифт; налоговый сценарий до PDF.
- Публикация: пользователь явно подтвердил «Да, опубликовать на сайте». Коммит 2c3c753 отправлен в main, четыре основных раздела проверены на действующем сайте.
- Подготовка конкурсных материалов: «посмотри задание», затем «выполняй». Результат: обновление README, описания процесса, скриншотов, сведений о лицензиях и пакета исходников.

Инструменты текущего этапа: Codex Desktop; навыки Sites (проверка способа размещения), Impeccable (UX/UI), redaktura (русские тексты), PDF (сборка и просмотр); независимый Codex-субагент; встроенный браузер CUA и его Playwright API; Node.js test runner; Git. Сайт размещён на Timeweb, сервис Sites для публикации не использовался. Изображения и тексты не генерировались через сторонние медиасервисы.
